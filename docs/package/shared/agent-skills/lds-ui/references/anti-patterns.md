# 안티패턴 — "생김새만 따온" 도입의 전형

완료 전 자가 점검 목록. 왼쪽이 하나라도 보이면 그 화면은 LDS처럼 보일 뿐 LDS가 아니다.

| ✗ 증상 | 위반한 계약 | ✓ 올바른 형태 |
|---|---|---|
| 스크린샷·데브툴에서 딴 `#EE5656` 직접 사용 | 색은 역할 | semantic 토큰 (`token-reference.json`에서 실명 확인) |
| 정상 상태에 초록 배지·램프 | 정상은 무채색 (배지 규칙) | 무채색 배지; 색은 이상 상태에만 |
| 위 규칙을 게이지 눈금·차트에 적용해 색 제거 | 배지 ≠ 측정값 | 측정값 인코딩 색은 유지 |
| 상태색 solid 채움 + 흰 글자 | signal은 점·아이콘·보더 전용 | surface/text 역할 쌍 사용 |
| 자체 래퍼에 `success/warning/error` prop | 톤 어휘 | `positive/cautionary/negative/signal/offline` |
| 카드 안에 카드, 보더 안에 보더 | 이중 테두리 금지 | embedded 변형; 부모가 경계 소유 |
| `font-size: 13px`, `margin: 7px` | 역할 램프·4px 그리드 | 타입 램프·간격 토큰 |
| "처리 중"을 `disabled`로 표현 | 상태 축 분리 | busy/pending 상태 (`aria-busy`) |
| loading/empty/error가 같은 빈 화면 | 상태 축 분리 | 3개 상태 각각 구현 |
| 새로고침 중 데이터를 지우고 스피너 | 복구 중 맥락 보존 | 마지막 정상 데이터 + 상태 표시 |
| 결측값을 `0`으로 표시 | 0을 지어내지 않는다 | `—` |
| 값 갱신마다 카드가 깜빡·펄스 | 모션은 데이터를 광고하지 않는다 | 정지; 인과 전이에만 모션 |
| `transition: all 0.3s` | 모션 토큰 | 명시 속성 + fast/base/slow |
| 선택 상태를 accent 배경색으로 | 선택은 기하, 색은 의미 | 컴포넌트의 selected 변형 사용 |
| 위험을 색으로만 표시 | 색만으로 말하지 않는다 | 색 + 아이콘/모양/텍스트 |
| 버튼 라벨 "확인" | 구체 동사 | 저장 / 삭제 / 다시 연결 |
| 요청 ACK에 "완료되었습니다" | sent≠accepted≠applied≠confirmed | "요청이 접수되었습니다" |
| 사용자에게 `ERR_TIMEOUT`, `IDLE` 노출 | 원시 enum 노출 금지 | 한국어 상태 명칭 |
| 값과 단위 문자열 이어붙이기 | 단위 결합 규칙 | `unit` prop / 공유 포매터 |
| `...` 세 글자 | 말줄임 | `…` |
| LDS 컴포넌트 내부를 CSS로 덮어써서 조합 변경 | 구조는 열되 조합은 닫힘 | 선언적 props; 부족하면 업스트림에 보고 |
| 도입 중 "이 토큰 값이 이상해서" 직접 수정 | 도입 ≠ 저작 | 업스트림에 별도 스코프로 보고 |
